# 墨印暗调·印刷质感

**墨印暗调** 是一种以编辑部印刷文化的克制与专业为内核的视觉运动。色阶收敛于暖墨底，强调低饱和的暖铜和细线描边，材质是纸张的细微纹理与油墨的层次。形式追求扁平而有分量的信息层级：衬线标题承托权威，机能无衬线承载数据，数字等宽以保持可比性。空间以呼吸为节奏，卡片间距如同排版的段落间距，留白是信息的沉默。

色彩策略以 oklch(14% 0.008 75) 为基底，强调色采用 oklch(77% 0.10 82) 的暖铜而非冷蓝，描边从发光改为 1px 实线，圆角收紧至 8-12px 范围。交互反馈依赖状态色与微动，拒绝彩色胶囊与彩虹渐变，所有强调通过透明度与描边而非背景色实现。

构图遵循 NapCat 控制台的仪式感：状态环为视觉锚点，统计条以细线分隔，日志流以等宽排印呈现。每个组件都是印刷版面中的一个栏位，字重、字距与行高经反复校准，形成可长时间阅读的专业密度。文本极少，信息靠空间与比例说话。作品必须呈现出被无数小时打磨的工艺感，仿佛印刷编辑在深夜校对页码，细微到 1px 的对齐与 0.02em 的字距都经手感验证，最终交付的不是界面，而是一本可交互的印刷品。
